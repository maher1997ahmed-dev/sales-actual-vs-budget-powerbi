# Sales Performance Analysis Dashboard (Actual VS Budget)

A professional Power BI dashboard designed to monitor, analyze, and evaluate corporate sales performance against predefined budget targets. This project provides deep financial and operational insights into product dynamics, monthly trends, and key performance variances.

## 📊 Live Dashboard Preview
![Dashboard Screenshot](dashboard.png)

## 🎯 Key Metrics & KPIs
The dashboard tracks vital business health metrics with dynamic filtering by **Product** and **Year**:
* **Total Actual Sales:** $23.00M (The total revenue generated across all products).
* **Total Budget Target:** $22.86M (The baseline target set for the fiscal periods).
* **Achievement Rate:** 100.57% (Successfully outperforming the baseline corporate target).
* **Sales Variance:** +$131.24K (A positive financial variance indicating favorable performance).
* **Variance Percentage:** 0.57% increase over the planned budget.

## 📈 Visualizations Breakdown
* **Actual VS Budget Gauges:** Micro-visuals tracking real-time status against targets and total achievement pacing.
* **Actual Sales by Product (Pie Chart):** Breakdown of product performance showing market share, led by **Aspen (39.2%)**, followed by **Carlota (33.74%)** and **Quad (27.06%)**.
* **Performance Over Time (Trend Analysis):** An integrated line/area chart displaying monthly sales accumulation and cyclical spikes compared to budget lines.
* **Monthly Financial Performance Matrix:** A clean corporate matrix table displaying exact figures for Actual, Variance, and Var% equipped with custom status indicator icons (Green/Red arrows) for instant decision-making.

## 🛠️ Tech Stack & Skills Demonstrated
* **Power BI Desktop:** Dashboard architecture, layout engineering, and theme customization.
* **Power Query (ETL):** Data cleaning, column profiling, formatting, and relational modeling.
* **DAX (Data Analysis Expressions):** Time intelligence functions, calculating custom variances, and dynamic achievement ratios.
* **UI/UX Design:** Corporate Grid layout alignment, color hierarchy optimization, and high-scannability design patterns.

## 🚀 How to View the Project
1. Download the `report.pbix` file from this repository.
2. Open it using **Power BI Desktop**.
3. Use the slicers at the top to filter data dynamically by specific products or fiscal years.
